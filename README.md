## 🚀 Getting Started

Follow these steps to run compatible Python programs from this repository.

### Prerequisites

- Python 3.x
- Git
- A code editor such as Visual Studio Code
- Jupyter Notebook, if required by the notebooks

### Step 1: Clone the Repository

```bash
git clone https://github.com/BGourav05/DATA-SCIENCE-AIML-USING-PYTHON.git
```

### Step 2: Open the Project Directory

```bash
cd DATA-SCIENCE-AIML-USING-PYTHON
```

### Step 3: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

On Linux/macOS:

```bash
source .venv/bin/activate
```

### Step 4: Install Dependencies

Install the packages needed for the particular program you want to run. For a project using the common data science libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### Step 5: Run a Python Program

```bash
python your_script.py
```

Replace `your_script.py` with the actual Python filename.

To launch Jupyter Notebook:

```bash
jupyter notebook
```
